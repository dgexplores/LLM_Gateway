What it does

Three moving parts, no framework maze.

01

Multi-provider routing

One POST /chat/completions call, one provider header. Maps openai, anthropic and ollama to their model strings inside main.py.

02

PII redacted logs

Emails, API keys and phone numbers are stripped from requests, responses and error text before a single line reaches stdout.

03

Redis circuit breaker

Opens after 5 failures, sleeps 30 seconds, resets on success. Unreachable Redis fails open, so an outage never blocks traffic.

Run it

Four commands to a local gateway.

  1. Install deps: pip install -r requirements.txt
  2. Copy .env.example to .env and fill your provider keys
  3. Start Redis on localhost:6379
  4. Serve: uvicorn main:app --reload, then run python -m pytest tests -q
